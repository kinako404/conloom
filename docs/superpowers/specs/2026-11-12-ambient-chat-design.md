# 氛围聊天：识趣退出与主动搭话 设计

日期：2026-11-12
上位：`docs/superpowers/specs/2026-11-12-conloom-p1-design.md`（P1 设计，下称“P1”）

## 1. 意图

P1 上线后，群主希望机器人更像“群友”：

1. **识趣退出**：群友 @ 机器人聊起来后（P1 已开启 60 秒连续对话窗口），如果对方转头和别人聊、或话题转走，机器人自觉不接话并结束这段连续对话。
2. **主动搭话**：群友平时聊天（没 @ 机器人）时，如果聊到了他以前常和机器人聊的话题，机器人可以主动接一句。是否被主动搭话、多频繁，是**每个群友自己可调**的；**只有主动 @ 过机器人的人**才会获得这项资格。

## 2. 用户已确认的决定

- 主动搭话按人开关，档位 `关 / 低 / 中 / 高`，群友用命令自己调。
- 资格：在本群 @ 过机器人或回复过机器人的消息（只发命令不算）；30 天没有再 @ 则资格失效。从没 @ 过的人永远不会被主动搭话。
- 获得资格时默认档位“低”。每人每天最多被主动搭话：低 2 次、中 4 次、高 8 次。对同一人至少间隔 30 分钟；全群每小时最多主动发言 4 次。
- 管理员有群总开关；`/pause` 同时停掉主动搭话。
- 主动发言以引用回复对方消息的形式发出；发出后对方进入连续对话窗口，之后按“识趣退出”处理。

## 3. 反目标（继承 P1 §2.3）

- 刷屏、对没 @ 过机器人的人搭话、对关掉主动的人搭话。
- 模型调用次数随群消息总量线性增长（P1 上位设计验收标准）。
- 跳过标记或画像关键词出现在群消息里。

## 4. 方案取舍

| 方案 | 做法 | 取舍 |
|---|---|---|
| **A（采用）** | 从每人 @ 机器人的消息中提取关键词，形成兴趣画像（带衰减，最多 50 个词）；候选消息先做便宜的关键词匹配与频率预算筛选，通过后才调用模型，由模型最终决定接话或输出跳过标记 | 不增加平时的模型调用；中文无分词，关键词靠二字词组 + 停用词，精度一般，由模型兜底 |
| B | 每次 @ 对话后另调一次模型提炼话题标签 | 话题更准，但每次 @ 多一倍模型调用 |
| C | 向量检索（P2 的 pgvector） | 质量最好，但依赖 P2 存储，当前不可用 |

## 5. 识趣退出

### 5.1 规则判定（不调模型）

连续对话窗口内的非 @ 消息，满足任一条件即**不触发**、按观察入库，并立即结束该用户的连续对话：

- 消息 @ 了机器人以外的人（`mentions` 中有 `user` 或 `all` 类型）；
- 消息回复的是另一位群友的消息（`reply_to` 指向非 Bot 消息）。

`Decide` 保持纯函数：`DecideInput` 新增 `MentionsOthers`、`ReplyToOther`；`Decision` 新增 `EndContinuation bool`。编排器据此调用调度器新方法 `EndContinuation(convKey, actorID)`。

### 5.2 模型判定

由连续对话触发（trigger `continuation`）的任务，在当前消息末尾附加固定提示（见 §7），要求模型在消息不是对它说的、或话题已转向别人时**只输出** `[[SKIP]]`。

- 模型输出（清理思考段之后）包含 `[[SKIP]]` → 不产生任何动作，任务 `succeeded`，`meta.review_result = "skipped"`，并结束该用户的连续对话。
- 跳过标记永远不能进入 Outbox：判定在输出审查之前完成，含标记的输出整条丢弃。

## 6. 主动搭话

### 6.1 群策略新增 `proactive` 段

```yaml
default_group_policy:
  proactive:
    enabled: true            # 群总开关
    default_level: low       # 获得资格时的默认档位：off|low|mid|high
    eligibility_ttl: 720h    # 多久没 @ 失去资格（30 天）
    user_cooldown: 30m       # 对同一人两次主动搭话的最短间隔
    group_hourly_limit: 4    # 全群每小时主动发言上限
    daily_limits: {low: 2, mid: 4, high: 8}   # 每人每天主动发言上限
```

- 校验：`default_level ∈ {off, low, mid, high}`；`eligibility_ttl ∈ [1h, 8760h]`；`user_cooldown ∈ [0, 24h]`；`group_hourly_limit ∈ [0, 60]`；各 `daily_limits ∈ [0, 100]` 且 `low ≤ mid ≤ high`。
- 兼容：库中已有的群策略版本没有 `proactive` 段，读取时用默认值补齐（零值 `ProactivePolicy{}` 视为缺失）。

### 6.2 资格与档位（新表 `conversation_members`）

每个（会话, 平台用户）一行：`last_engaged_at`、`proactive_level`、`level_set_by_user`、`interests`（JSON：词 → 权重）、`updated_at`。

- 群聊中触发为 `mention`、`reply`、`continuation` 的消息（不含命令）：用该消息文本更新兴趣画像；其中只有 `mention`、`reply` 更新 `last_engaged_at`（连续对话中的消息不续期资格）。首次建行时档位 = `default_level`；用户没设过档位时跟随群当前的 `default_level`，用户自己设过的档位保留不覆盖。
- 资格 = `last_engaged_at` 距今 < `eligibility_ttl` 且档位 ≠ `off`。

### 6.3 兴趣画像（新包 `internal/interest`，纯函数）

- 词项：ASCII 单词（≥2 字母，转小写）与连续汉字的二字词组；去掉内置停用词（常见虚词与口头禅二字组合，如“我们、什么、怎么、这个、没有、可以、就是、不是、知道、觉得、现在、时候、还是、一下、真的、哈哈”等），单条消息内去重。
- 更新：已有权重 × 0.9，再给本条消息的每个词项 +1；只保留权重最高的 50 个。
- 匹配：候选消息的词项与画像前 N 个词的交集至少 K 个——低档 N=20、K=2；中档 N=30、K=1；高档 N=50、K=1。

### 6.4 候选筛选（全部满足才进入模型）

1. 群聊；决策为 `observe`；消息不过时（P1 的 `stale_task_after`）；群未暂停；`proactive.enabled`。
2. 发言者有资格（§6.2）。
3. 文本 ≥ 4 个字；不是命令；没有 @ 任何人；没有回复其他群友的消息。
4. 该用户在本会话没有排队或运行中的任务。
5. 兴趣匹配（§6.3）。
6. 发言预算：今天已对该用户主动发言次数 < 档位上限；距上次对该用户主动发言 ≥ `user_cooldown`；全群最近一小时主动发言 < `group_hourly_limit`。
7. 评估预算（限制模型调用）：今天对该用户的评估次数 < 3 × 档位上限；全群最近一小时评估次数 < 3 × `group_hourly_limit`。
8. 距机器人与该用户的上次接触 ≥ `user_cooldown`：上次接触 = 机器人回复该用户（任何触发方式）或该用户的连续对话结束（规则或模型退出）的时间。只保存在进程内存中（重启后清空），维护任务每小时清理 24 小时前的记录。

通过后：写一条 `evaluated` 记录，建 trigger 为 `proactive` 的任务（走调度器，享有合并窗口与回复间隔；模型准入优先级低于普通回复）。调用模型前与发送前都会重新检查总开关、暂停、档位与发言预算，不再满足则按跳过处理、不调用模型或不发送。模型回复 → 引用回复对方消息发出，写一条 `sent` 记录，标记连续对话；模型输出 `[[SKIP]]` → 不发送。@ 别人或回复其他群友的消息不会并入该用户待处理的主动任务。

记录表 `proactive_log`：`conversation_key, platform_user_id, kind(evaluated|sent), task_id, created_at`；计数按时间窗口查询，重启后依然有效；维护任务定期清理 7 天前的记录。

### 6.5 命令

| 命令 | 权限 | 作用 |
|---|---|---|
| `/主动`、`/proactive` | 所有人 | 查看自己的档位、资格、今日已被搭话次数 |
| `/主动 关|低|中|高`、`/proactive off|low|mid|high` | 有资格的人 | 设置自己的档位（标记为用户设定） |
| `/主动 全群 开|关`、`/proactive group on|off` | 管理员 | 群总开关（生成新群策略版本） |

没有资格的人设置档位时回复“先 @ 我聊几句，才能开启主动搭话。”；私聊中回复“主动搭话只在群聊里使用。”。`/help` 文案加入 `/主动`。

## 7. 固定提示文案（附在当前消息末尾，不改动系统提示前缀）

- 连续对话：`【提示】这条消息没有 @ 你，只是对方在你回复后接着说的。如果它不是在和你说话，或者话题已经转向别人，只输出 [[SKIP]]，不要输出其他内容。`
- 主动搭话：`【提示】没有人 @ 你，这是你在主动搭话。这个人以前常和你聊：{前 5 个兴趣词，用顿号连接}。只有当你能自然、简短地接上这个话题时才回复（一两句）；如果不合适、话题无关、或对方明显在和别人聊，只输出 [[SKIP]]，不要输出其他内容。`

## 8. 可观测性

- `conloom_continuation_exits_total{reason="rule|model"}`
- `conloom_proactive_total{result="evaluated|sent|skipped"}`
- 日志不记录兴趣词与正文（遵守 P1 隐私约束）。

## 9. 测试与验收

- 单元：`interest` 的词项提取、衰减、匹配阈值；`Decide` 的两条退出规则；跳过标记处理；候选筛选每一条；三类预算；资格过期；档位命令与权限；旧策略补齐默认值；迁移 0002。
- 端到端（假模型）：连续对话中 @ 别人 → 不回复且窗口结束；模型输出 `[[SKIP]]` → 无动作；有资格且话题匹配 → 一条主动回复；没 @ 过的人同样话题 → 不回复且零模型调用；超出预算 → 零模型调用；`/主动 关` 后不再主动。
- 线上：部署后观察指标与日志一天。
